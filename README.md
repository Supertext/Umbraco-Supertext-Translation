# Supertext Translation for Umbraco

Translate Umbraco documents into other languages with **Supertext AI**: one click on **Translate with Supertext** in the backoffice translates a page — text, rich text and the text inside block lists and block grids — into the languages you choose and saves them as drafts to review and publish.

Works with Umbraco 17 LTS (tested) and 18, .NET 10. Guides follow in `docs/`.
